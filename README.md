# Безопасный маршрут

Сайт строит пешеходный маршрут из точки А в точку Б, выбирая не кратчайший
путь, а наименее опасный при разумном удлинении — и объясняет, почему маршрут
проложен именно так.

Вся логика работает в браузере: граф улиц тянется из OpenStreetMap через
Overpass API по участку вокруг точек, A* считает два маршрута — кратчайший и
безопасный. Ни сервера, ни сборки, ни API-ключей.

## Запуск

```sh
npm run serve      # http://localhost:8000
```

Открывать через локальный сервер: по `file://` браузер блокирует ES-модули и
запросы к Overpass.

## Что считается опасностью

Стоимость ребра графа — `длина × (1 + вес_безопасности × риск)`, где риск
складывается из:

- **освещение** — тег `lit` в OSM; ночью штраф втрое выше, чем днём;
- **тип пути** — тропа через парк или пустырь дороже жилой улицы, подземный
  переход дороже всего;
- **«глаза на улице»** — магазины, кафе, остановки в 50 м снижают риск;
- **ваши зоны** — отмеченные на карте круги: «обходить» или «не ходить вовсе».

Все веса лежат в одном файле `src/config.js` и правятся без изменения
алгоритма.

**Оговорка.** Это эвристика по открытым данным, а не гарантия. Данные OSM об
освещении неполные, криминальная статистика не используется. Инструмент
помогает сравнить варианты и не подходит для чрезвычайных ситуаций.

## Структура

| Файл | Ответственность |
|---|---|
| `src/config.js` | веса риска, лимиты, endpoints |
| `src/geo.js` | haversine, point-in-polygon, bbox |
| `src/osm-fetch.js` | Overpass и кэш в localStorage |
| `src/graph.js` | элементы OSM → узлы и рёбра |
| `src/enrich.js` | парки и POI → признаки рёбер |
| `src/risk.js` | оценка риска ребра (чистая функция) |
| `src/router.js` | A* с функцией стоимости извне |
| `src/explain.js` | причины обхода и дельта длины |
| `src/route-provider/local.js` | реализация `RouteProvider` в браузере |
| `src/ui/` | карта, панель, зоны опасности |

Роутинг спрятан за интерфейсом `RouteProvider`, чтобы заменить его на вызов
бэкенда (FastAPI + OSMnx), не трогая интерфейс. Контракт и план описаны в
`docs/superpowers/`.
